字符串

概念卡 02 前置：变量与数据类型 8 道分层自测 7 条可核查来源
60 秒速读

字符串就是引号里的文字，可以按位置切、也可以按分隔符拆。

位置从 0 开始，s[0:5] 取前五个字，s[-1] 是最后一个字。 字符串不能改：replace() 只是返回新串。[1] 中文标点与英文标点不是同一个字符，这是新手第一大坑。[6]

💡 通俗理解 · AI 辅助整理 · 本人已核查

字符串像一条贴了编号的珠链：第一个字编号 0，第二个编号 1，也可以从右往左数成 -1、-2。想取一段，就说清从哪开始、到哪结束（结尾那位不算）。有些方法像换珠子——换了以后原来的链子没变，只是多了一条新链。最容易出事的是引号：全角逗号"、"和半角","长得像，电脑却当成两个字符。

学习目标

  • 能解释字符串为什么可以按位置取值，以及索引从 0 开始意味着什么。
  • 能区分 s[0:5] 与 s[5] 取到的东西有什么不同，并说出切片为什么不会越界报错。
  • 能写出用 split()、strip()、replace() 把一条采访记录拆成字段的代码。
  • 能判断一段文字里哪些是中文标点、哪些是英文标点，并说出这个区别为什么会让匹配失败。

核心问题

索引为什么从 0 开始，不从 1？
因为索引指的是字符之间的位置，不是第几个字。官方教程给出的理解方式是： 第一个字符的左侧标 0，最后一个字符的右侧标 n（n 是字符串长度）。[1] 这样 s[:i] + s[i:] 永远等于 s，切片的算式才自洽。 记法上只要记住一句话：第一个字是 s[0]，取最后一个字用 s[-1]。
s[0:5] 为什么取到 5 个字，不是 6 个？
因为切片的规则是含起点、不含终点。起止索引之差就是切出来的长度， 5 - 0 = 5。[1] 另外一条常见的困惑是：索引越界会报 IndexError，但切片不会—— s[4:42] 只会给到末尾，多余的部分被自动忽略。
为什么 replace() 之后原来那个变量没变？
因为字符串是不可变对象：一旦创建就不能改动。 a.replace('a', 'A') 不会修改 a 指向的那条数据， 而是新建一条 'Abc' 返回给你。[1] 要用这个结果，就得写 b = a.replace('a', 'A')。 这条规则对字符串的所有方法都成立，也正因为不可变，字符串才能安全地当字典的键（见概念 04）。
"王某某，男，45岁" 为什么用 split(',') 拆不开？
因为记录里用的是中文全角逗号"'，'"，而代码里写的是英文半角逗号 "','"。 这两个字符看起来像，编码上却是两个完全不同的字符，程序不会把它们当成同一个。 《标点符号用法》给汉语书面语规定的句内点号，形式就是全角写法。[6] 正确写法是 record.split('，')；如果数据来源混杂， 稳妥做法是先用 replace() 把两种逗号统一成一种，再切。
f-string 和直接用加号拼接有什么不一样？
加号只能把两段文字首尾相接，而且两边必须都是字符串——想要放进去一个整数， 得先自己转成字符串，否则报错。f-string 在字符串前面加一个 f， 花括号里可以直接写变量甚至表达式，运行时先算好再放进去， 还能在冒号后面写格式说明符（例如保留两位小数）。[4] 官方教程把它列为三种格式化方式里最简洁的一种。[3]

结构化解释

是什么

字符串是引号里的文字序列。单引号和双引号完全等价， 要表示引号本身就用反斜杠转义（\'）或者换一种引号； \n 表示换行，\t 表示制表符，前面加 r 则不转义； 三引号 '''...''' 可以写多行。[1] 索引取的是单个字符，切片取的是子串，还有一个内置函数 len() 返回长度—— 在 Python 里，"长度为一的字符串"就是单字符，没有单独的类型。[1]

为什么

三个原因。第一，新闻工作的原料就是文字：标题、正文、采访记录、读者留言， 在程序里全是字符串。字段提取这一步，本质就是字符串操作。 第二，只有字符串能被切成一批：split() 的返回值就是列表—— 这是通往概念 03（列表）和概念 11（中文分词）的入口，jieba 做的事情说到底也是把一个句子切成一批词。 第三，不可变带来安全：因为字符串改不了，它可以被当作字典的键， 也可以放心地在多处共享而不会被别的代码改掉。[2]

怎么工作

  1. 位置编号：从左往右从 0 开始；从右往左用负数，-1 是最后一个字符。 索引越界报 IndexError。[1]
  2. 切片：写 s[起:止]，含起点、不含终点。省略起点默认从 0 开始， 省略终点默认到末尾。切片不会因为越界而报错。
  3. 清洗与拆分：strip() 去掉首尾空白，replace() 换内容， split() 按分隔符拆成列表，startswith() 判断开头。[2]
  4. 拼回模板：用 f-string 把变量填进稿子模板，例如 f'{name} 记者今日报道'。[3]
  5. 记住不可变：以上方法都不会改动原字符串，只返回新串。想留下结果，必须赋值给变量。
写法作用新闻场景
s.split('，')按分隔符切成一个列表 把 '王某某，男，45岁' 拆成三个字段分别取用
s.replace('，', ',')把内容替换成别的，返回新串 把混在数据里的全角逗号统一成半角，再统一处理
s.strip()去掉首尾空白 清掉从导出的 CSV 带进来的空格，否则 ' 486' 不是数字
s.startswith('本报讯')判断是不是以某段开头，返回 True/False 从一批稿件里筛出以"本报讯"开头的消息类稿件

应用案例

一百二十条读者来电，卡在一个逗号上。 2026 年 4 月，某市晚报的实习记者小周要把 120 条读者来电记录整理成表格。 这套记录是热线系统自动生成的，格式统一，每条都长这样： '王某某，男，45岁，反映某小区停水三天'。

她的第一版代码只有一行：record.split(',')。 结果整条记录只拆出一段，等于没拆。原因不是代码写错了，而是记录里用的是 全角逗号，她写的是半角逗号—— 两个字符肉眼几乎一样，在计算机里却是完全不同的两个。[6] 改成 record.split('，') 之后，120 条一次全部拆开。

第二个坑紧跟着来了：拆出来的第二段有的写成 '男'， 有的写成 ' 男'（前面带一个半角空格），做统计时会被当成两类。 加上一步 .strip() 就干净了。[2] 最后她把结果拼成通稿模板 f'{name}，{age} 岁，来自 {addr}' 打印出来核对， 120 条一目了然。[3]

示意（推演场景，非公开报道）

上面的人物与记录内容是教学推演。 但"全角标点混进数据"这件事在真实工作中极常见：从网页复制、从微信导出、 从旧系统迁移的数据，都可能两种逗号混着用。稳妥做法是先把标点统一，再动手分析。

概念辨析

邻近概念 与本概念的区别 一句话区分点
字符与字节 len() 数的是字符数；编码成 UTF-8 之后才能得到字节数。 一个汉字编码后通常占 3 个字节，一个英文字母只占 1 个。 len('中文') 是 2，len('中文'.encode('utf-8')) 是 6。 数"几个字"用字符串，数"占多大"要先编码。[5]
列表（概念 03） 字符串是"一条"，索引取到的是单个字符；列表是"一列"，索引取到的是一整项。 两者的连接点是 split()：它把一条字符串变成一列。 字符串按位置取出一个字，列表按位置取出一项；split() 是从前者到后者的桥。
中文标点与
英文标点		 汉语书面语的句内点号有规范形式（全角），这与英文的半角标点在编码上是不同字符， 但长度都算 1。它们长得很像，程序不会自动等同。 肉眼像不等于相等，这是字符串处理里最常见的假象。[6]
f-string 与
加号拼接		 加号只能把两段文字接起来，而且两边必须都是字符串；f-string 的模板里可以直接写变量和表达式， 运行时先算好再放进去，还能带格式说明符。 加号只会"接"，f-string 会"算好再放"。[4]
元数据字段名
（NewsML-G2）		 行业标准给内容条目规定了固定的字段名——标题用 headlines、署名用 by、 主题用 subjects，不能随手改成别的。[7] 这和"用固定分隔符切字符串"是同一个道理：名字先统一，后面才接得上。 字符串管"这段文字长什么样"，字段名管"这段文字在内容条目里扮演什么角色"。
