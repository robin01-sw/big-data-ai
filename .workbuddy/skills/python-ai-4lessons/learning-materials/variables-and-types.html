变量与数据类型

概念卡 01 前置：本课起点 8 道分层自测 6 条可核查来源
60 秒速读

变量就是给一条数据贴上一个名字，之后可以反复用它。

数据有四种类型：int 整数、float 小数、str 文字、bool 真假，type() 可查。 名字可以改贴到别的数据，旧值被覆盖。Python 不必先声明类型，类型属于数据。[1]

💡 通俗理解 · AI 辅助整理 · 本人已核查

把变量想成一张不干胶标签。写下 title = '老旧小区改造'，就是拿起写着 title 的标签，贴在稿子上。标签不是稿子本身；撕下来贴到别处，原稿不变，标签也不再指它。数据也有身份：手机号写成 13800，加了引号就是文字，不是数字，加法也做不了。所以先弄清贴的是什么，再谈拿它做什么。

学习目标

  • 能解释变量名和数据本身是两回事：名字可以换，数据不会因为换名字而改变。
  • 能区分 int、float、str、bool 四种基本类型，并说出每种在新闻稿件里对应哪类字段。
  • 能写出把一条稿件的标题、字数、是否配图分别存进变量的代码，并用 type() 检查每一个。
  • 能判断一个变量名是否合法，并说出为什么不能用 list、type、print 当变量名。

核心问题

变量是不是一个"盒子"，把数据装进去？
不是盒子，更像不干胶标签。Python 执行 title = '……' 时，先造出右边那条数据， 再让左边的名字指向它。[4] 后面再写一次 title = '……'，是换一张标签贴到新数据上，不是把盒子里的旧东西倒出来。 理解这一点，才能解释为什么两个名字可以同时指向同一条数据。
为什么有的"数字"不能做加法？
因为引号里的数字是文字。'45' + '5' 得到 '455'， 那不是相加，是把两段文字粘起来。要算数，得先确认它真的是 int 或 float—— 从表格、网页、Excel 里读进来的数据，经常是带引号的。 拿不准就先 type() 看一眼，这是最省事的一步。[1]
为什么 Python 不用像 Java 那样先写 int x = 1？
因为类型挂在数据上，不挂在名字上。名字只是一个指向，可以先指整数、后指文字。 这类语言叫动态语言，Java 那一类叫静态语言。[4] 代价是：类型不匹配的错误不会在写代码时就报出来，而要等程序跑到那一行才报。
名字取成 list 或 type 会怎样？
会把 Python 自带的名字盖掉。之后写 list('abc') 时，调用的其实是你那个变量， 程序会报 TypeError。所以命名规则除了"不能用数字开头、不能用关键字"， 还有一条：别用内置名。PEP 8 给的替代办法是加一个尾下划线，比如 class_。[5]
重新赋值以后，原来的值去哪了？
如果已经没有任何名字指向它，Python 之后会把它回收，你就再也取不到了。 但如果之前写过 old = title，那 old 仍然指着旧数据。 所以"覆盖"覆盖的是名字的指向，不是那条数据本身。[4]

结构化解释

是什么

变量是名字指向数据这件事本身。Python 里的等号是赋值语句： 先把右边的值算出来，再让左边的名字指过去。它和数学里的等号不是一回事—— 数学上 x = x + 2 不成立，程序里却是最常见的写法：算出 x + 2，再让名字指向这个新结果。[4] 数据类型则是数据自带的身份，决定了这条数据能做什么、不能做什么。

为什么

两个原因。第一，类型决定运算的含义。'12' + '3' 是拼接得到 '123'， 而 12 + 3 是相加得到 15；同一个加号，结果完全不同。 新闻里最常见的坑就在这：从外部文件读来的数字，往往是文字形式。[1] 第二，名字决定代码能不能读。同一段处理流程要在几十篇稿件上重复用， 叫 title、word_count 的名字，三个月后自己还看得懂； 叫 a、b、c 的名字，等于给自己埋坑。PEP 8 把这条写得很直接： 代码被阅读的次数远多于被编写。[5]

怎么工作

  1. 算出等号右边：如果是一个表达式，先算出结果。
  2. 在内存里创建这条数据（一个对象）。
  3. 让等号左边的名字指向它。整数值是 int，带小数的是 float， 引号里的文字是 str，只有 True 和 False 两个取值的是 bool。[1]
  4. 再赋一次值，就是让同一个名字改指另一条数据。旧数据不会因为改指而消失，只是失去了名字。
  5. 想确认名字现在指着什么，用 type(名字) 查；想要有几个字符或几项，用 len(名字) 查。[3]
类型写法举例新闻场景里的对应字段
int 整数486、-3、2026 字数、年份、阅读量、留言条数
float 小数3.14、0.62、486.0 平均字数、占比、增长率。注意：除法 / 总是返回 float，9 / 3 得到 3.0
str 文字'第一现场'、'486' 标题、正文、记者署名、日期。'486' 与 486 是两条不同的数据
bool 真假True、False 是否配图、是否通过校验、是否含敏感词。注意大小写，true 写法会报错
命名规则四条：只能用字母、数字、下划线；不能用数字开头；不能用关键字（if、for、class 等）； 别用内置名（list、type、print 等）。PEP 8 另外建议全小写加下划线，并且不要用单个字母 l、O、I 当名字，因为某些字体里它们和 1、0 分不清。[5]

应用案例

一次录稿，被一个空格卡住。 2026 年 3 月，某都市报数据组要把 30 篇「老旧小区改造」系列稿录进表格，统计平均字数。 实习生小林刚开始只写了一个变量 text，每篇整段塞进去，回头再数——数到第 7 篇就放弃了。 改成三个变量之后，流程立刻清楚了：title 存标题、word_count 存字数、 has_photo 存是否配图，每录完一条就把三个变量打印在同一行里，30 篇十分钟录完。 这一步看起来只是起了几个名字，做的却是数据新闻里最基础的一件事： 动手分析之前，先把信息整理成一行一条、一列一义的表格。[6]

真正的坑出现在第 12 篇。 那篇的字数在源表格里带着一个空格，写作 ' 486'。数字看上去没问题， 但它是带引号的文字，类型是 str。[1] 一算平均字数程序就报错，小林打印 type(word_count) 才发现问题所在—— 把 ' 486' 换成 486，程序就好了。 这类"看起来是数字、其实是文字"的情况，是处理外部数据时最常见的一类事故。

概念辨析

邻近概念 与本概念的区别 一句话区分点
常量 常量是"不打算改"的量，Python 没有任何机制阻止你改， 只用全大写的名字（如 MAX_WORDS = 800）表示这是一个约定； 变量则随时可以改指向。 常量靠约定约束，变量靠"随时可改"定义。[4]
数据类型 类型是数据自带的身份，名字只是指向。同一个名字今天指 str、 明天指 int，类型会跟着数据走，不会跟着名字走。 换名字不改变类型，换数据才改变类型。[2]
列表与字典
（概念 03、04）		 一个变量装一条数据；列表和字典是"容器"，把很多条数据装在一起， 让一个名字指向一整批。容器本身也是数据，也有类型。 变量问"这条叫什么"，容器问"这一批怎么放"。
人工标注的规则表 规则表规定待标注的每个字段是什么意思、怎么记、取值范围是什么； 程序里的变量名，就是那张表落到代码里的样子。两者都要先定义再使用， 但规则表属于标注前的约定，变量名属于内存里的名字。 规则表管"这个变量在标注口径里代表什么"，代码变量管"这条数据在内存里叫什么"。
