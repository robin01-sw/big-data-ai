二、数据类型速查

输出格式记牢：<class 'xxx'> 里的 class 暂时读作「类型」即可， 真正的「类」含义要等面向对象那部分才展开。

输出名字例子与提示
<class 'int'>整数3、-7。integer 的缩写。
<class 'float'>浮点数3.14、3.0。只要带小数点就是 float。
<class 'str'>字符串"Hello"、"3"。加了引号就是文本。
<class 'bool'>布尔值True / False，只有两个值。
<class 'NoneType'>空值None，表示「什么都没有」，不是 0 也不是空字符串。
<class 'list'>列表[1, 2, 3]，方括号，可改。
<class 'tuple'>元组(1, 2, 3)，圆括号，建好不能改。
<class 'set'>集合{1, 2, 3}，无序、不重复。
<class 'dict'>字典{"姓名": "小明"}，键值对。
三个最容易混的点
  • 3 是 int，3.0 是 float——值相等，类型不同。
  • 3 是 int，"3" 是 str——引号一包就换了身份，"3" + 1 会直接报错。
  • int(3.9) 得到 3：直接砍掉小数，不四舍五入。

四、这次踩的坑（本节最值得复习）

五条报错，四条是「名字问题」。按报错原文对号入座即可。

报错原文真正原因怎么改
TypeError: 'tuple' object is not callable 之前写过 print = ("句子1", "句子2")，把内置函数 print 覆盖成了一个元组；元组不能加括号调用。 先点 重启内核（或执行 del print）恢复内置函数， 再把那行改成两次 print("…") 调用。
NameError: name 'list1' is not defined 定义时写的是 list，使用时写成 list1，名字对不上。 另外 list 本身是内置名，占用它会埋下同类隐患。 两处改成同一个名字，并避开内置名，例如统一用 nums。
NameError: name 'chat' is not defined Python 没有 chat 这个内置函数，前面也没定义过——多半是漏跑了课件里 「先定义 chat」的那一格，或该函数需要自己接 API。 回到课件把定义代码补跑；若想真调大模型，需自己写 def chat(...) 并配置 API key。
NameError: name 'Print' is not defined 把 print 写成了大写 Print。Python 区分大小写， print 与 Print 是两个不同的名字。 改成全小写 print(...)。
（不是报错）弹窗「重启 Jupyter kernel？所有变量都将丢失」 重启会清空内存里的变量值，但单元格里的代码一行都不会丢。 放心点「重启」，再点「全部运行」，变量就回来了。前提是文件已保存（Ctrl+S）。

五、带走这几条

三条护身符

1. 先定义，再使用——函数、变量都是如此，顺序错了就 NameError。
2. 名字前后要一致，且注意大小写——print 不是 Print。
3. 别拿内置名当变量名——print、list、str、sum 一旦被赋值覆盖，原来的功能就没了。

这三条覆盖了本次全部报错。
看到报错的通用两步

① 先看最后一行：NameError 是名字问题，TypeError 是类型/调用问题， IndentationError 是缩进问题。
② 再看 Cell In[..], line N 与那个 ---> 箭头，它精确指出出错的那一行。

把这两步做顺，大部分新手报错可以自己定位。
关于变量 vs 代码

变量活在内存里，重启就没了；代码活在文件里，保存了就在。所以「重启」从来不是危险操作， 它是把环境恢复干净的最省事手段。
