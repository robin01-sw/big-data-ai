四、本次四类报错的原因与改法

这四类报错属于同一个根因（名字问题），因此每条只写一句话； 最后一条 TypeError 涉及原理，单独展开。

报错原文原因 → 改法
NameError: name 'list1' is not defined 定义的是 list、用的是 list1，名字不一致 → 两处改成同一个名字。
NameError: name 'Print' is not defined 大小写写错，Print ≠ print → 改小写。
NameError: name 'chat' is not defined 没定义就调用 → 先把课件里定义 chat 的那格跑一遍。
TypeError: 'tuple' object is not callable 把函数名当变量赋值覆盖了，展开见下。
展开：为什么给 print 赋值以后，它就不能用了

因为 Python 里 print 只是一个名字，它默认贴在「内置的那个打印函数」上。 你写 print = ("a", "b")，等于把这个名字撕下来贴到了一个元组上—— 名字没变，指向的东西变了。之后 print("你好") 就成了「在元组后面加括号」， 而元组不能这样调用，于是报 TypeError。

这不是 bug，是 Python 允许你覆盖任何名字（包括内置的）。想复原：重启内核，或执行 del print。

关于「重启 Jupyter kernel，所有变量都将丢失」这个弹窗

变量活在内存里，重启就清空；代码活在文件里，保存过就不会丢。所以可以放心点「重启」， 再点「全部运行」，变量就都回来了。

五、相关概念补充（本次未讲，但很快会用到）

以下五条与本次内容紧挨着，每条都控制在三行以内，能看懂下一次报错即可。

补充 1 · 名字与命名空间（为什么名字会被覆盖）

Python 里的「名字」（变量名、函数名）只是贴在某个值上的标签，它们分别存在不同的命名空间里。 查找顺序是从近到远：本地 → 外层 → 全局 → 内置（可以记作 LEGB）。

所以你在全局定义了 print，它就把内置那个遮住了——这叫遮蔽（shadowing）， 也是第四节 TypeError 的成因。对应第四节报错

实用结论：print、list、str、sum、type、id 别拿来当变量名。

补充 2 · 可变类型与不可变类型

不可变：int、float、str、bool、tuple。你「改」它，其实是在旁边造了个新值，原来那个没动。
可变：list、dict、set。它们可以就地修改，改完还是同一个对象。

这带来一个容易出错的写法：a = [1, 2] 之后写 b = a; b.append(3)， a 也会变成 [1, 2, 3]——因为 a 和 b 指的是同一个列表。

它也解释了为什么元组不能 append、为什么集合是无序的。解释列表与元组的区别

补充 3 · 函数与方法的区别

两者都是「能加括号执行的代码」，区别在归属：函数独立站着，如 print(x)、 len(x)；方法得挂在某个对象上，如 s.append(1)、小明.introduce()。

点号（.）的意思是「取这个对象身上的某个东西」——取数据就是属性， 取函数就是方法。方法是函数的一种，只是被装进了对象里。后面学类与对象的基础

补充 4 · 条件的真假判断（truthiness）

if 后面不一定要写比较式。0、0.0、空字符串 ""、空列表 []、空字典 {}、空集合、None 这几种一律当假，其余为真。

所以 if 列表: 是「非空才做」的常用写法。注意 if not x 比 if x == 0 更宽——它把 ""、[] 也算进去了，判断前先想清楚要哪一个。

补充 5 · 类型转换与 input 的返回值

"3" + 1 会报 TypeError：文本和数字不能直接相加，得先转 int("3") + 1。三个最常用的转换是 int()、float()、str()。

最容易踩的坑：input() 拿到的永远是字符串，哪怕你输的是 20。 想做算术必须写成 int(input("年龄："))，否则会得到 "20" 而不是 20。 后续练习会用到

六、本次要记住的五条规则

关于命名与调用（对应第四节报错）

1. 先定义，再使用——顺序错了就报 NameError。
2. 名字前后一致，并注意大小写——print 不是 Print。
3. 不要用内置名当变量名——被覆盖后原有功能就没了。

关于类型与输入（对应第五节补充）

4. 给可变类型赋值不是复制——b = a 之后改 b，a 也会变。
5. input() 返回的永远是字符串——要参与算术，先 int() 转换。

两个书写习惯

缩进就是语法。Python 用缩进表示「谁属于谁」，惯例 4 个空格，同一块必须对齐； 错了会报 IndentationError。这次分支的缩进写对了，保持。

看报错先看最后一行。它告诉你错误类型（NameError 名字问题 / TypeError 类型或调用问题 / IndentationError 缩进问题）， 再看 ---> 箭头指的那一行。
