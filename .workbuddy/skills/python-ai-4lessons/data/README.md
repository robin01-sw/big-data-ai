# 示例数据说明

本目录存放「Python 与 AI 四节课」课上要用的数据。**先看第一节。**

---

## 一、⚠️ 这些数据是什么

**全部是 AI 用模板合成的虚构内容，不是真实新闻、不是真实评论。**

- 由 `生成示例数据.py` 生成，固定随机种子 `20260917`，结果可复现
- 出现的地名（云岭市 / 江川市 / 南屏市 / 东河县 / 白汀区 / 石桥镇）、
  媒体名（云岭日报 / 示例通讯社 等）、机构名、人名、数字 **全部是虚构的**
- 不含任何真实采集的数据，**不要**用于研究、引用、投稿或对外发布

> 这也适用于课程自己的「四条红线」第 3 条。以后拿真实数据做练习时，
> 采集前先问「这份数据是否本就公开」；本套数据因为是合成的，所以可以放心练手。

## 三、格式约定

- 所有文件：**UTF-8 无 BOM**，换行用 **LF**
- CSV 分隔符是半角逗号。**字段内容里不包含半角逗号**，所以不需要处理引号转义
- ⚠️ **CSV 用 Excel 直接双击可能显示乱码**（Excel 默认按本地编码解析）。
  正确打开方式：Excel →「数据」→「从文本/CSV」→ 编码选 UTF-8。
  用 pandas 则直接 `pd.read_csv(路径, encoding="utf-8")`

## 四、第 2 课：`语料/` 怎么用

用 `pathlib.Path("语料").glob("稿件_*.txt")` 遍历。每篇的结构是：

```
标题：……
来源：……          ← 部分文件**没有这一行**
时间：……          ← 三种格式混用
正文：
……

```

**脏数据是故意埋的，它就是练习素材。** 一张表：

| 类型 | 命中 | 说明 |
|---|---|---|
| 缺「来源」行 | 7 篇 | 008 016 024 032 040 048 056 —— 合并成表时会出现空值，先想好怎么处理 |
| **完全重复的文件** | 2 对 | `012 = 059`、`033 = 060` —— 去重练习的靶子 |
| 正文里段落重复 | 14 篇 | 同一篇内有一段出现两次 |
| 中英文标点混用 | 24 篇 | 半角 `,` `.` 与全角 `，` `。` 混在一起 |
| 行尾多余空格 | 25 篇 | `.strip()` 的用武之地 |
| 行首有缩进 | 32 篇 | |
| 正文中间有多余空行 | 30 篇 | 会造成空行被当成一条记录 |
| 整篇首尾有多余空白 | 23 篇 | |
| 时间格式不统一 | 46 篇有「时间」行 | `2026-08-12 09:30` 13 篇 / `2026/8/12` 14 篇 / `8月12日` 19 篇；另有 14 篇**没有**时间行 |

**建议产出**：`output/干净语料.csv`，至少含 `文件名, 标题, 来源, 时间, 正文` 五列，
并在报告里写清每一步做了什么（去了什么、按什么规则去重、缺失的「来源」怎么填）。

## 五、第 3 课：`新闻标题_待标注.csv`

列：`编号, 标题, 来源, 发布时间`。**故意不预置标签** —— 按课程设计，
标签体系与判定规则要在课堂上共创，先给了标签，那一步就没有意义了。

**教师视角：刻意埋了 12 条跨题材边界标题**，用来在共创规则时引爆讨论
（「科技还是农业？」「文化还是经济？」「一条标题能不能只归一类？」）：

> 编号 **18 43 55 102 105 114 121 142 200 235 241 295**

配套的 `../课件/标注表_第3课.csv` 已把编号和标题填好，
`类别 / 判定依据 / 标注人 / 是否边界情况 / 备注` 五列留空，直接发给学员即可。

## 六、第 4 课：`新闻评论_待分析.csv`

列：`编号, 关联标题编号, 评论内容, 平台`。200 条，**同样没有情感标签**。

这里的「没有标签」是刻意的：第 4 课的重点是**看模型错在哪儿**，不是对答案。
评论混合了 7 类语气：

| 语气 | 条数 | 备注 |
|---|---|---|
| 正面 | 32 | |
| 负面 | 32 | |
| 中性 | 28 | |
| **反讽** | 28 | 模型杀手：字面积极、实际消极 |
| **双重否定** | 20 | 模型杀手：「不能说没有道理」 |
| 疑问 / 建议 | 30 | 情感倾向本身就不明确 |
| 网络用语 | 30 | 「绝了」「好家伙」这类，正负全靠语境 |

按课程设计，snownlp 在这批数据上会明显跑偏（它的训练语料以电商评价为主），
**这个错误是教学设计的一部分**，不要修，要拿来当例子讲。

## 八、已知限制（如实列出）

- 句式由模板合成，**重复感明显强于真实语料** —— 不适合用来讲「语言的多样性」
- 数字是随机拼的，偶尔出现不合常理的比例（如「覆盖 86 个社区、15 户居民」）
- 六个题材分布均等，真实新闻不会这么平均
- 停用词表是常见高频词的经验合集，**不是任何权威词表**
- 第 3 课若把训练好的模型存成 `.pkl`，`.gitignore` **仍会挡住它**（`*.pkl` 未开例外）。
  需要入库的话得单独加一条例外，否则会重演「做完的东西被静默忽略」
