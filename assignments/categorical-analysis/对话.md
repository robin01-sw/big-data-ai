# 类别变量练习 · 父母职业关联分析（对话记录）

> 作业要求：对「类别变量练习数据」做数据清理和转化，分析父母职业之间是否存在关联。
> 本文整理了与 AI 助手协作完成该作业的全过程：需求是怎么提的、AI 给了什么方案、我核查了什么、最终结论是什么。
> **说明：本文由 AI 辅助整理，分析代码与结论均已本人运行、核查。**

---

## 一、数据是什么

原始文件 `类别变量练习数据.csv`（GBK 编码，Excel 直接另存）只有两列，都是**自由填答的单位名称**：

| 列名 | 示例值 |
|---|---|
| 父亲工作 | 市农业农村局、中铁六局太原铁路建设公司、盛泰房地产公司、老姐饺子馆、家庭主妇 |
| 母亲工作 | 市实验中学、鑫智点交通设施有限公司、北京路九洋菜市场刘伟鲜面店、家庭主妇、（空） |

共 **53 条**记录（其中 1 条母亲栏为空；有 4 条内容完全重复，可能是不同家庭填了同一单位，保留不删）。

这类数据不能直接做统计：**它不是类别变量，而是文本**。所以作业里说的"清理和转化"至少包含三层：

1. **清理**——去空格、去换行（有单元格里带 Excel 软回车，把一条记录拆成了两行）、空值统一；
2. **转化**——把"单位名称"这种自由文本归并成可统计的**职业类别变量**；
3. **再分析**——类别变量之间的关系用**列联表 + 卡方检验**，而不是相关系数。

---

## 二、与 AI 的对话过程

### 第 1 轮：先问思路，别急着写代码

**我问**：这份数据两列都是公司/单位名字，怎么变成类别变量？父母职业之间"有没有关联"该怎么测？

**AI 答**：先把单位名归到**就业单位性质**这一层，再检验两个类别变量的独立性。推荐做法：

- 分类维度选"单位性质"而不是"具体行业"，因为原始填答太细（同一个局就有财政局、审计局、住建局……），按行业分会出现几十个只出现一次的类别，列联表直接崩掉；
- 归成 6 类：公共部门（党政机关·事业单位）/ 国有企业 / 民营企业 / 个体经营 / 家庭主妇 / 无业·未填；
- 检验用 **Pearson 卡方独立性检验**（H0：父亲职业与母亲职业相互独立），关联强度用 **Cramér's V**；
- 因为样本只有 53，单元格会很稀疏，**必须再补一个不依赖"期望频数≥5"假设的检验**——于是加了 5000 次随机重排的**置换检验**，并把 6 类合并成 3 类（体制内 / 市场化 / 家庭与未就业）做一次稳健性复核。

我觉得这个思路站得住：分类维度可解释，检验方法有交叉验证，不是只报一个 p 值了事。

### 第 2 轮：清理环节踩到的两个坑

| 问题 | 具体表现 | 处理 |
|---|---|---|
| 单元格内换行 | `"市经济合作局\n"`、`"县住房保障中心\n"` 在 CSV 里是带引号的多行字段 | 读入后对每个单元格去掉所有空白字符（含 `\n`、全角空格），再去首尾标点 |
| 编码 | 文件是 GBK，直接 `encoding='utf-8'` 会报错 | 按 `utf-8-sig → utf-8 → gbk → gb18030` 顺序尝试，实际命中 gbk |
| 无效填答 | `家庭父母`、`家庭父亲`、`无`、空值 | 都不是有效单位信息，统一归为"无业·未填"，并在文中说明，不硬猜 |

另外检出了 4 条完全重复的记录。**没有删除**——同一单位可能是两个不同学生的家长，删了会凭空减少样本；只在数据里加了 `是否重复` 标记。

### 第 3 轮：分类规则怎么定才不算"瞎归"

AI 一开始只给关键词规则（含"局"就是机关、含"公司"就是企业），我按这个跑了一遍，把 91 个原始值逐个打出来核对，发现规则会判错三类：

| 原始值 | 规则会判成 | 实际应归 | 原因 |
|---|---|---|---|
| 陕西省水利水电第三工程局 | 公共部门（含"局"） | 国有企业 | 名字带"局"但是施工企业 |
| 银光聚银化工有限公司 / 市给排水（集团）有限公司 | 民营企业（含"公司"） | 国有企业 | 前者是兵器工业集团下属企业，后者是市政公用国企 |
| 区建豪汽修中心 / 万盛体能拓展中心鑫多米便利店 | 公共部门（含"中心"） | 个体经营 | 带"中心"但是街边门店 |

所以最终的做法是**「关键词规则 + 人工逐条修正」两级**：规则先跑，凡是判错的写进 `OVERRIDES` 字典手工指定，脚本会把每个值的判定依据（命中哪个关键词 / 人工指定）输出成 `mapping_table.csv`，可以一条条查。

这一步我认为是整个作业最需要"人"的地方——**AI 只能给规则，规则对不对得自己看数据**。

### 第 4 轮：结果出来了，怎么读

先看边际分布（`outputs/边际分布.png`）：

| 职业类别 | 父亲（人，占比） | 母亲（人，占比） |
|---|---|---|
| 公共部门 | 24（45.3%） | 23（43.4%） |
| 国有企业 | 5（9.4%） | 3（5.7%） |
| 民营企业 | 11（20.8%） | 7（13.2%） |
| 个体经营 | 10（18.9%） | 7（13.2%） |
| 家庭主妇 | 1（1.9%） | 10（18.9%） |
| 无业·未填 | 2（3.8%） | 3（5.7%） |

再看列联表（`outputs/列联表热力图.png`，行百分比）：

- 父亲在**公共部门**的 24 户里，母亲也在公共部门的有 **18 户（75.0%）**，母亲是家庭主妇的 **0 户**；
- 父亲在**民营/个体**的 21 户里，母亲是家庭主妇的有 **8 户（38.1%）**，母亲在公共部门的只有 4 户（19.0%）。

### 第 5 轮：检验结果

| 检验 | χ² | df | p（卡方） | p（置换检验） | Cramér's V | 期望频数<5 的格子 |
|---|---|---|---|---|---|---|
| 六类细分 6×6 | 47.660 | 25 | **0.0041** | 0.0110 | 0.424 | 35/36（97%） |
| 合并三类 3×3 | 18.192 | 4 | **0.0011** | 0.0010 | 0.414 | 3/9（33%） |

两种粒度、两种检验，结论一致：**p < 0.01，拒绝独立性假设**；Cramér's V ≈ 0.42，属于**中等偏强**的关联（0.1 弱、0.3 中等、0.5 强）。

我特意问过 AI：6×6 表 97% 的格子期望频数不到 5，卡方近似还成立吗？它的回答是"不成立，所以要看置换检验"——置换检验不需要正态/期望频数假设，直接模拟"随机配对时 χ² 能有多大"，得到 p=0.011，仍显著。这一条我认可，也是我保留 3×3 表的原因：合并后单元格才勉强够用。

补充一个 2×2 的对照（父亲是否体制内 × 母亲是否有工作）：

| | 母亲有工作 | 母亲为家庭主妇 |
|---|---|---|
| 父亲体制内 | 28 | **1（3.4%）** |
| 父亲体制外 | 15 | **9（37.5%）** |

χ²（连续性校正）= 7.847，df = 1，**p = 0.0051**。方向很直观：父亲在体制内（机关/事业单位/国企）的家庭，母亲几乎都在外工作；父亲在体制外的，母亲回归家庭的比例高得多。

## 三、结论（可直接作为简答题答案）

> 对 53 份样本先做文本清理（去空白、处理单元格内换行、空值与无效填答统一为"无业·未填"），再把父亲、母亲的工作单位名称按单位性质归并为 6 类职业变量（公共部门、国有企业、民营企业、个体经营、家庭主妇、无业·未填），最后用列联表与卡方独立性检验分析两者关系。
>
> 结果显示：**父母职业之间存在显著关联**（6×6 表 χ²=47.66，df=25，p=0.004；合并为 3 类后 χ²=18.19，df=4，p=0.001；5000 次置换检验 p=0.011 / 0.001，结论一致），关联强度为中等偏强（Cramér's V≈0.42）。
>
> 具体表现为**同类婚配倾向**：父亲在党政机关或事业单位的 24 户中，75% 的母亲同样在公共部门，无一人为家庭主妇；而父亲在民营企业或个体经营的 21 户中，38.1% 的母亲为家庭主妇。以"父亲是否体制内 × 母亲是否为家庭主妇"做 2×2 检验，差异同样显著（χ²=7.85，df=1，p=0.005）。
>
> 需要注意：样本量仅 53，细分表 97% 的单元格期望频数小于 5，卡方近似不可靠，故以置换检验与合并类别后的结果为主要依据；职业类别由单位名称人工归并，个别判断（如"××工程局"归国企而非机关）依赖填答信息，存在主观性。

---

## 四、局限（写在作业里会被认为想清楚了）

1. **样本小、单元格稀疏**：53 户分到 36 个格子，卡方近似不满足，所以补了置换检验和合并类别两重稳健性检查；
2. **转化带主观性**：单位名不等于职业，只能判断就业单位性质；同一单位内部的岗位差异（领导 / 普通职工）无法识别；
3. **无效填答**：`家庭父母`、`家庭父亲`、`无`、空值共 5 处，统一归"无业·未填"，未做猜测性填补；
4. **相关不等于因果**：显著关联只能说明两类职业在样本中共同出现，不能推断"父亲职业决定了母亲职业"。

## 五、提交物与复现方式

| 文件 | 内容 |
|---|---|
| `step1_clean.py` | 读取 + 清理 + 类别转化（含 `OVERRIDES` 人工修正与关键词规则） |
| `step2_analyze.py` | 列联表 + 卡方 + Cramér's V + 置换检验 + 绘图 |
| `outputs/cleaned_data.csv` | 清理后的明细（原始值、清理值、职业大类、是否重复） |
| `outputs/mapping_table.csv` | 91 个原始值 → 职业大类 的对照表及判定依据 |
| `outputs/列联表_详细6x6_频数.csv` / `_行百分比.csv` | 6×6 列联表 |
| `outputs/列联表_粗分3x3_*.csv` | 合并三类后的列联表 |
| `outputs/检验结果汇总.csv` | 两套检验的统计量汇总 |
| `outputs/列联表热力图.png` | 观察频数 + 行百分比热力图 |
| `outputs/边际分布.png` | 父母职业各自的人数分布 |
| `outputs/step1_report.txt` / `step2_report.txt` | 完整运行日志（含每步判断） |

复现：把 `类别变量练习数据.csv` 与本目录放在一起，依次运行

```bash
python step1_clean.py
python step2_analyze.py
```

依赖：`pandas`、`numpy`、`scipy`、`matplotlib`（本机 Python 3.12.10 实测通过）。
