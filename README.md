# 大数据与人工智能（Big Data & AI）

个人课程学习仓库，用于存放课程笔记、代码示例和作业。

## 环境配置

- **Python**: 3.12
- **编辑器**: VS Code
- **版本控制**: Git + GitHub

## 目录结构

```
big-data-ai/
├── README.md          # 本文件：课程说明
├── requirements.txt   # Python 依赖清单
├── main.py            # 示例代码
├── data/              # 数据集（请勿上传大文件）
├── notes/             # 课程笔记
└── homework/          # 作业
```

## 常用命令

```bash
# 安装依赖
pip install -r requirements.txt

# 运行示例
python main.py

# Git 常用操作
git status          # 查看状态
git add .           # 添加所有更改
git commit -m "备注" # 提交
git push            # 推送到 GitHub
```
